Example of CSS Columns

This shows an example of turning a list in to multiple columns that run top-to-bottom then left-to-right.

The CSS needed is:

ul.exampleList
{
  column-width: 200px;
  -moz-column-width: 200px;
  -webkit-column-width: 200px;
}
