I've been playing around with <a title="Google" href="http://www.google.co.uk/" target="_blank">Google</a>'s customised search recently. It is great, I can create a filter on <a title="Google" href="http://www.google.co.uk/" target="_blank">Google</a> that means that, for the majority of the time, I get the results that I want. The majority of the time I search <a title="MSDN" href="http://msdn.microsoft.com/" target="_blank">MSDN</a>, <a title="Code Project" href="http://www.codeproject.com/" target="_blank">Code Project</a>, my own website and my blog.
<ul>
	<li><a title="MSDN" href="http://msdn.microsoft.com/" target="_blank">MSDN</a> is the main documentation for all of <a title="Microsoft" href="http://www.microsoft.com/" target="_blank">Microsoft</a>'s developer tools. It contains nearly everything I want to know.</li>
	<li><a title="Code Project" href="http://www.codeproject.com/" target="_blank">Code Project</a> fills in the gaps with examples of how to do certain things</li>
	<li>My own website and blog are included because I often write things down so I don't forget... Then I forget, so I have to find it again. It is much easier searching my own blog for something than it is to search the wide internet.</li>
</ul>
I'm sure I'll be adding sites to the filter as I go along. The <a title="Microsoft" href="http://www.microsoft.com/" target="_blank">Microsoft</a> DPEs' blogs are likely to be added shortly as will a number of other blogs that I read regularly. All will be developer focused so if you want to use my custom search you can be assured that you won't end up getting crazy results back about cute kittens.
