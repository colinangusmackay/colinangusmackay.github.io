		<p>DDD5 seems to have sold out in less that a week this time. I've also been looking at the <a href="http://www.developerday.co.uk/ddd/agendaddd5lineup.asp">final agenda</a> to get an idea of what I'd like to see. There are a few time slots where I'd like to see two sessions at once so I'll be thinking hard about which we go for.</p>
<p>For the moment my choice is as follows:</p>
<p> <strong>An introduction to Unit Testing with Mock Objects</strong> <em>(Presentation)</em> <strong><a href="http://www.developerday.co.uk/ddd/speakers.asp#Colin Angus Mackay">Colin Angus Mackay</a></strong></p>
<p>Mock objects are stand-in dummy objects that don't have any functionality behind them, they just return the values to the application that the real object would have returned. Unit tests are supposed to test isolated bits of code. Mock objects ensure that if the code you are testing calls something external to the class being tested you don't have to worry about what the actaul real class does. This talk expects the audience to be familiar with the concepts of Unit Testing and will introduce the concepts of Mock Objects.</p>
<p><strong>Team Foundation Server - the answer to all project management problems?</strong> <em>(Presentation)</em> <strong><a href="http://www.developerday.co.uk/ddd/speakers.asp#Richard Fennell">Richard Fennell</a></strong></p>
<p>Sick of SourceSafe? Is <a title="Microsoft" target="_blank" href="http://www.microsoft.com/">Microsoft</a>'s Team Foundation Server the answer to all your problems? In this session I will cover the key components and usage of TFS, installation issues, the range of third party tools available and how to write your own tools using the API. The session will include demos of cool addins and tips drawn from bitter experience.</p>
<p><strong>An Appraisal of "Object Thinking"</strong> <em>(Presentation)</em> <strong><a href="http://www.developerday.co.uk/ddd/speakers.asp#Alan Dean">Alan Dean</a></strong></p>
<p>Have we got object-orientation all wrong? "Object Thinking" (ISBN 0-7356-1965-4) by David West asserts that we have. Alan Dean explores this assertion, and demonstrates self-describing objects / self-evaluating rules with code examples. <a target="_blank" href="http://thoughtpad.net/alan-dean/object-thinking.html">More details...</a> </p>
<p><strong>Agile Methods for ISVs</strong> <em>(Presentation)</em> <strong><a href="http://www.developerday.co.uk/ddd/speakers.asp#Gary Short">Gary Short</a></strong></p>
<p> We've all heard of agile methods but when they are spoken of it is mostly in the context of the enterprise. Being an ISV and being agile is a different kettle of fish. In this talk I'll explain the differences between life as an ISV and life in the enterprise and then I'll show you how to adapt agile methods for use in the ISV world.</p>
<p><strong>Multithreading patterns</strong> <em>(Presentation)</em> <strong><a href="http://www.developerday.co.uk/ddd/speakers.asp#Cristian Nicola">Cristian Nicola</a></strong></p>
<p>In the modern computers is more and more important to use multiple threads to benefit of the multi-core CPU readily available. This session explores multithreading patterns from the flows, data, resources and exceptions points of view, without actually being tied to a particular programming language.</p>
