<a title="Google" href="http://www.google.co.uk/" target="_blank">Google</a> maps has a cool feature that allows you to draw annotations on a map. I've created one detailing the transportation links (bus station, railway station and car parks) nearest the <a href="http://maps.google.co.uk/maps/ms?ie=UTF8&amp;msa=0&amp;msid=113091888199208468176.000001122365c713b06f5&amp;hl=en&amp;om=1&amp;z=16">location of the upcoming Scottish Developer events</a>.

To create a map like this all you need is an account with <a title="Google" href="http://www.google.co.uk/" target="_blank">Google</a>, then press the My Maps button on the <a href="http://maps.google.co.uk/">Google Maps</a> page.
