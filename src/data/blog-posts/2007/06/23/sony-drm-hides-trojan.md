Further to my post last week about <a href="http://blogs.wdevs.com/colinangusmackay/archive/2005/11/01/11037.aspx">Sony's malware disguised as DRM </a>it seems that a trojan is now taking advantage of the Sony malware.

From The Register: <em>"This means, that for systems infected by the Sony DRM rootkit technology, the dropped file is entirely invisible to the user. It will not be found in any process and file listing. Only rootkit scanners, such as the free utility <a href="http://www.sysinternals.com/utilities/rootkitrevealer.html">RootkitRevealer</a>, can unmask the culprit," warns Ivan Macalintal, a senior threat analyst at security firm Trend Micro.</em>

The full story can be found here: <a href="http://www.theregister.co.uk/2005/11/10/sony_drm_trojan/">First Trojan using Sony DRM spotted</a>
