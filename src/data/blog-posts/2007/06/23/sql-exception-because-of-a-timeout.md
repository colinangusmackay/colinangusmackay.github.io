You think it would be easy to find information on exactly what error number a <span style="font-family:'Courier New';">SqlException</span> has when the command timed out. But, it isn't. <a title="MSDN" href="http://web.archive.org/web/20051105094148/http://msdn.microsoft.com/" target="_blank">MSDN</a>, for all that it is normally an excellent resource, fails to even mention that the <span style="font-family:'Courier New';">Number</span> property of a <span style="font-family:'Courier New';">SqlException</span> or <span style="font-family:'Courier New';">SqlError</span> can even be negative. (I suppose if I am to be fair, it doesn't say it can be positive either). What it does say is exactly this:
<blockquote style="margin-right:0;"><a href="http://web.archive.org/web/20051105094148/http://msdn.microsoft.com/library/default.asp?url=/library/en-us/cpref/html/frlrfSystemDataSqlClientSqlExceptionClassNumberTopic.asp"><span style="font-family:Verdana;">This number corresponds to an entry in the <strong>master.dbo.sysmessages</strong> table</span>.</a>[<a href="http://web.archive.org/web/20051105094148/http://msdn.microsoft.com/library/default.asp?url=/library/en-us/cpref/html/frlrfSystemDataSqlClientSqlExceptionClassNumberTopic.asp" target="_blank">^</a>]</blockquote>
If you look at the <span style="font-family:'Courier New';">sysmessages</span> table, you will notice that all the numbers are positive. So, why am I concerned about negative numbers? Because sometimes the <span style="font-family:'Courier New';">SqlException.Number</span> property returns negative numbers, and therefore it does not correspond to an entry in the <span style="font-family:'Courier New';">sysmessages</span> table. So, the documentation is not telling the whole story.

I want to find out when an <span style="font-family:'Courier New';">SqlException</span> happened because of a timeout. The easiest, and I should imagine, the more reliable way of checking a <span style="font-family:'Courier New';">SqlException</span> for any particular error message is to check the <span style="font-family:'Courier New';">Number</span> property in case the message <span style="font-family:'Courier New';">description</span> has been localised or changed for some other reason. For most cases this is perfectly fine. I can check the <span style="font-family:'Courier New';">sysmessages</span> table for the description for the error that I am wanting to handle and I can check for that number when I catch a <span style="font-family:'Courier New';">SqlException</span>. But, there isn't any error number for a timeout.

The exact error message that is in the <span style="font-family:'Courier New';">SqlException</span> is
<blockquote style="margin-right:0;"><span style="font-family:'Courier New';">Error: System.Data.SqlClient.SqlException: Timeout expired. The timeout period elapsed prior to completion of the operation or the server is not responding.</span></blockquote>
So, if the error is potentially because the server isn't responding then the error message cannot be generated on SQL Server itself. How would it generate this error message if the server isn't responding? The error, I can only assume, is being generated by ADO.NET. Why do I say I can only assume? Because after spending some time fruitlessly googling for a definitive answer I have yet to find one.

The best answer I've found is some sample code, that happens to check the <span style="font-family:'Courier New';">Number</span> property of the <span style="font-family:'Courier New';">SqlException</span> in a <span style="font-family:'Courier New';">switch</span> statement and next to <span style="font-family:'Courier New';">case -2:</span> is the comment <span style="font-family:'Courier New';">/* Timeout */</span>

So, at the moment I'm working on the assumption that <span style="font-family:'Courier New';">-2</span> just means a timeout caused the execution of the <span style="font-family:'Courier New';">SqlCommand</span> to fail. I don't like developing software in this way because if there is a bug in the future I cannot be certain that this code is okay or if sometimes <span style="font-family:'Courier New';">-2</span> is something else, or perhaps sometime a timeout is something other than <span style="font-family:'Courier New';">-2</span>

<hr />Original Comments:

-2 is the error code for timeout, returned from DBNETLIB, the MDAC driver for SQL Server. So, its not ADO.NET.

A full list of possible error numbers can be found by using Reflector on System.Data.SqlClient.TdsParser.ProcessNetLibError.
