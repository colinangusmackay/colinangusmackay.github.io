<p align="center"><a title="Photo Sharing" href="http://www.flickr.com/photos/colinangusmackay/698865571/"><img height="169" alt="Pointless error message" width="471" border="0" src="http://farm2.static.flickr.com/1198/698865571_813d0c5837_o.png"></a></p>
<p>Well here's a pointless error message from Microsoft Powerpoint 2007 running on Windows Vista. </p>
<p>What actually happened is that I picked from the list of recently opened files a presentation that was saved to a USB key which is no longer present. While the dialog title bar does give useful information to the user, the main message is filled with useless rubbish as far as a user is concerned.</p>
<p>Pressing cancel doesn't immediately help - It just repeats the message. You have to click cancel a fair few times before it eventually tells you something useful - Such as it can't actually find the file with the given path name.</p>
<p>Why wasn't the user told immediately that it couldn't locate the file instead of being presented with a bunch of hex?</p>
