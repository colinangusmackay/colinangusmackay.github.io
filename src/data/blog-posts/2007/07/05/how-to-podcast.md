		<p>The <a href="http://www.nxtgenug.net">NxtGenUG</a> have just released <a href="http://www.nxtgenug.net/Podcasts.aspx?PodcastID=35">an excellent podcast on how to do a podcast</a>. This was recorded at the Microsoft Community Leaders Day last week. If you are interested in doing your own podcast then this contains some excellent information about how to go about it. </p>
<p>Also mentioned is a SQL Server Community Day along the same lines as Developer Day (DDD) that is going to happen on the 6th October at Microsoft's campus in Reading.</p>
<p>Some of the tips include using <a href="http://audacity.sourceforge.net/">audacity</a> for editing, and <a href="http://www.incompetech.com/m/c/royalty-free/">Kevin MacLeod</a>'s work for the music.</p>
