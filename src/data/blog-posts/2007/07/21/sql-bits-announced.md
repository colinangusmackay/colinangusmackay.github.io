		<p>Finally <a href="http://www.sqlbits.com/">SQL Bits</a> has been anounced. It follows in the same ethos as DDD (Developer Day) but focuses on SQL Server. It is being organised by the best community minded SQL people in the UK, so it is bound to be an excellent day.</p>
<p>At the moment the call for speakers is open and my only regret on that front is that the new spatial elements of SQL Server 2008 have not be released into the CTP yet and that is a subject that I'm most interested in and would probably have something to talk about if it was there.</p>
<p>So, a date for your diary: 6th Ocotber, 2007</p>
