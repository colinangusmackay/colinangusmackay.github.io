		<p>It seems there is a website out there called BuzzyCode. Naturally it is a software development website and it contains lots of information about how to do certain things in software. All very well and good so far, except for one thing. There is a lot of plagarised work on the site.</p>
<p>A few days ago, the site was discovered by a member of Code Project, and he soon discovered that it contained a lot of ripped off articles that were originally written by people who are members of Code Project. Some members of Code Project managed to speak to (or otherwise communicate with) the people that run the site and it would appear that their story doesn't add up. </p>

<p>Heck they even seem to steal from each other (or perhaps forgot that an article had already been copied and added it under a different author's name). For example: <a rel="nofollow" href="http://www.buzzycode.com/ShowArticles-id_493.aspx">http://www.buzzycode.com/ShowArticles-id_493.aspx</a> and <a rel="nofollow" href="http://www.buzzycode.com/ShowArticles-id_596.aspx">http://www.buzzycode.com/ShowArticles-id_596.aspx</a> are almost identical  - Mostly the formatting is different.</p>
<p>Finally, in a wonderfully ironic twist their website contains an article on reasons to offshore development to India which contains this titbit: "<a rel="nofollow" href="http://www.buzzycode.com/ShowArticles-id_983.aspx">Indians are also known for their honesty and integrity therefore you can be rest assured that all intellectual and other virtual property will not be infringed upon and belong to the original party.</a>" Maybe they should have added "except those that set up this website"</p>
