		<p>I've been a bit busy recently, so I've finally got round to blogging about upcoming community events. As it has all stacked up it is all going in one post.</p>
<p><strong>October</strong>:</p>
<p><a href="http://www.guysmithferrier.com/">Guy Smith-Ferrier</a> will be talking to the <a href="http://www.northeastscotland.net">North East Scotland .NET User Group</a> in Dundee on the 2nd October about "<a href="http://www.northeastscotland.net/dnn4/Forum/tabid/59/forumid/1/postid/22/view/topic/Default.aspx">Visual Studio 2005 IDE Tips and Tricks</a>"</p>
<p><a href="http://www.guysmithferrier.com/">Guy Smith-Ferrier</a> will be talking to <a href="http://www.scottishdevelopers.com">Scottish Developers</a> in Edinburgh on the 3rd October about <a href="http://www.scottishdevelopers.com/modules/newbb/viewtopic.php?viewmode=flat&amp;topic_id=1074&amp;forum=1100">"Astoria" and Using ClickOnce and XBAPs to deploy Windows Forms and WPF applications</a>.</p>
<p><a href="http://www.sqlbits.com/">SQLBits</a> is full, although a waitlist is in operation, so you can always register and hope for a cancellation.</p>
<p><a href="http://www.paterson.co.uk/">Jim Paterson</a>, author of <a href="http://www.amazon.co.uk/Definitive-Guide-db4o-Stefan-Edlich/dp/1590596560/ref=pd_bbs_sr_1/203-9362558-6538355?ie=UTF8&amp;s=books&amp;qid=1190323759&amp;sr=8-1">The Definitve Guide to db4o</a>,  will be talking to <a href="http://www.scottishdevelopers.com">Scottish Developers</a> in Glasgow on the 10th October about <a href="http://www.scottishdevelopers.com/modules/extcal/event.php?event=3">db4o: An embedable database for object oriented environments</a>.</p>
<p><strong>November</strong>:</p>
<p><a href="http://www.frankkerrigan.com/">Frank Kerrigan</a> and Steve Phillips will be talking to Scottish Developers in Glasgow in a joint event with the Scottish SQL Server User Group on the 14th November.</p>
<p><a href="http://www.developerday.co.uk"><font color="#0066cc">DDD6</font></a> has been announced. It will be held on 24th November and, as usual, it is at the Microsoft Campus in Reading. There is also a poll for to find out where you want DDD7 to be as they are going to move it around. At the moment the North East of England is winning! So, everyone from Scotland needs to get on that website and vote for Scotland!!!</p>
<p><strong>December</strong>:</p>
<p>Rob Lally will be talking to Scottish Developers in Glasgow about GWT and GUICE on the 12th December.</p>
<p><strong>2008</strong>:</p>
<p>Developer Day Scotland will be taking place in Spring 2008. Watch this space for more information.</p>
