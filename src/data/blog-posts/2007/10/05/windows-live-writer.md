		<p>Today I was encouraged to try <a href="http://get.live.com/betas/writer_betas" target="_blank">Windows Live Writer</a> as a way to create blog entries. So this is my first test entry using Live Writer which is supposed to be able to publish the entries directly to the blog without me actually having to visit the blog admin page at all.</p>  <p>First feature that is nice is that the keyboard shortcut for adding hyperlinks is the one I am used to (Ctrl+K) which is shared with Word and Expression Web.</p>  <p>Unfortunately I don't see a download for a plug in to create Technorati tags. That could be quite useful and if I have time, and that is a big IF, I might look in to writing one myself.</p>
