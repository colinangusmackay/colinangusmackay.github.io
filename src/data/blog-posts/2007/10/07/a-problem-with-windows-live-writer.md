		<p>I have an external USB hard disk that I use to store all my documents on. I move it between my laptop and my desktop PC so that when I'm out with my laptop I still have access to all my files. And when I get back I don't have any synchronisation issues.</p>  <p>However, I don't seem to be able to tell Windows Live Writer where to save my drafts (e.g. A blog folder on my external HDD) so it all ends up in My Documents.</p>  <p>I don't suppose it will be too difficult to take a USB stick and copy the posts from one to the other, but I'd rather just plug the HDD in and go.</p>  <div class="wlWriterSmartContent" id="scid:0767317B-992E-4b12-91E0-4F059A8CECA8:f983ba1d-7283-4a5d-898f-bd8d144f023a" style="display:inline;margin:0;padding:0;">Technorati Tags:  		<a href="http://technorati.com/tags/USB%20HDD/" rel="tag">USB HDD</a> 		,  		<a href="http://technorati.com/tags/Windows%20Live%20Writer/" rel="tag">Windows Live Writer</a> 		,  		<a href="http://technorati.com/tags/Blog/" rel="tag">Blog</a> 		</div>
