		<p>Oh no! I've been podcasted. <a href="http://www.craigmurphy.com/blog/?p=742" target="_blank">Craig Murphy caught up with me at SQL Bits and demanded to know what I thought of the sessions that I attended</a>. I'm not sure if I really am that repetitious of if it was just that we stopped and started recording a few times because the background noise got a bit excessive at times and I had to restart what I was saying.</p>  <p>Just to make sure I got something out of it too I told him about two SQL Events coming up here in Scotland. On the 24th October there is <a href="http://www.sqlserverfaq.com/?eid=101" target="_blank">a talk about SQL Backups (and I'm doing a micro-presentation on SQL Injection Attacks)</a>. Then on the 14th November there are <a href="http://www.scottishdevelopers.com/modules/extcal/event.php?event=7" target="_blank">two talks about different aspects of SQL Server</a>. The first is the start on a series on Reporting Services, this is the "Introduction to Reporting Services". The second in a talk about SQL Server Managed Objects (SMOs).
