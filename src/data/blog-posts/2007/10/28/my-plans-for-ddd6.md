I've been looking through the agenda for DDD6 and there is a lot of fantastic sessions there and I'm going to have to make some hard choices on the day. So what appeals to me:

In the first session I'm interested in <a href="http://www.sturmnet.org/blog/" target="_blank">Oliver Sturm</a>'s "Business Applications with WPF - The Full Monty" and also <a href="http://iancooper.spaces.live.com/" target="_blank">Ian Cooper</a>'s N-Tier applications with LINQ.

In the second session I've also got two conflicting sessions that I want to see: <a href="http://silverlightuk.blogspot.com/" target="_blank">Chris Hay</a>'s "Introduction to Silverlight 1.1 (no pesky javascript in this talk)" and <a href="http://www.garyshort.org/" target="_blank">Gary Short</a>'s "My Favourite Patterns"

The third session is my toughest choice as there are three things I'm quite interested in. The second part of Oliver Sturm's "Business Applications with WPF - The Full Monty", <a href="http://mikehadlow.blogspot.com/" target="_blank">Mike Hadlow</a>'s "Why do I need an Inversion of Control Container?" and <a href="http://www.benlamb.com/" target="_blank">Ben Lamb</a>'s "Being Lazy with Microsoft PowerShell"

After lunch I'm up with my "<a href="http://blog.colinmackay.net/archive/2007/10/17/638.aspx" target="_blank">Question Time on the subject of Recruitment</a>". The panel includes <a href="http://idunno.org/" target="_blank">Barry Dorrans</a>, <a href="http://www.sarahblow.com/" target="_blank">Sarah Blow</a>, <a href="http://www.frankkerrigan.com/" target="_blank">Frank Kerrigan</a> and Karl Lightfoot. I would like to see some of the other sessions at that time, but naturally I'd like you to come and see my session.

Finally, I'd like to see Barry Dorran's session on "Web Services? We don't need no web server". Although, if I don't feel I can take any more information in I'll probably end up in "Swaggily Fortunes"

To round it all off I'm sure there will be a geek dinner somewhere - although that's not been announced yet.
