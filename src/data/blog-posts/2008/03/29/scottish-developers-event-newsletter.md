		<p>As some of you may have been aware, Microsoft recently formally launched Visual Studio 2008, Windows Server 2008 and SQL Server 2008 in their Heroes Happen Here launch event in Birmingham. Well, if you didn’t make it to Birmingham don’t worry about it because we are doing our own community launch in Glasgow. I’m currently getting all the updates from DHL about the progress of the swag (prizes) as it makes its way from Redmond. So there will be lots of giveaways on the night, so if you want a chance of winning some free software then let us know you’re coming. It is the usual venue at Glasgow Caledonian University, but we’re starting a little bit earlier than normal and we’re on a Thursday.</p>  <p>Also, if you have not registered as a delegate for <a href="http://developerdayscotland.com/main/Default.aspx">Developer Day Scotland</a>, now is your chance. The <a href="http://developerdayscotland.com/main/DelegateRegistration/tabid/69/Default.aspx">delegate registration</a> is now open. There are three tracks in total for this day long event with some <a href="http://developerdayscotland.com/main/Agenda/tabid/68/Default.aspx">excellent presentations</a> lined up.</p>  <h3> </h3>  <h3><u><a href="http://www.scottishdevelopers.com/modules/extcal/event.php?event=48">Visual Studio 2008 Community Launch</a></u></h3>  <p>Thursday April 3<sup>rd</sup> in Glasgow starting at 18:30</p>  <p>Speaker: Mike Ormond</p>  <p>In this session we will explore what’s new for web developers in Visual Studio 2008. Demos will include the new HTML designer, CSS enhancements, improvements when working with scripting and the three new ASP.NET 3.5 data controls. We may even throw a bit of AJAX in there, just for fun!</p>  <h3><u><a href="http://www.sqlserverfaq.com/?eid=111">Scottish SQL Server User Group</a></u></h3>  <p>Wednesday 23<sup>rd</sup> April in Edinburgh starting at 18:30</p>  <p>Speakers: Alistair Board &amp; Satya SK Jayanty</p>  <p>Alistair will be talking about the 6 W’s of SQLDiag. Satya will be talking about SQL Server 2008 – Declarative Management Framework Concepts &amp; Database Problem Solutions with Policy Management.</p>  <h3><u><a href="http://developerdayscotland.com/main/Default.aspx">Developer Day Scotland</a></u></h3>  <p>Saturday 10<sup>th</sup> May in Glasgow starting at 09:00</p>  <p>This is a three track day long event. 2 Developer! Developer! Developer! tracks and 1 SQLBits track. <a href="http://developerdayscotland.com/main/DelegateRegistration/tabid/69/Default.aspx">Delegate registration</a> is open. </p>
