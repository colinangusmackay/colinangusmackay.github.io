		<p>I'll be speaking at the <a target="_blank" href="http://www.scottishdevelopers.com/">Scottish Developers</a> event in Glasgow on the 10th June 2008 at the Continuing Professional Development Centre at Glasgow Caledonian University.</p>
<p>I've be giving an introduction to the new XML classes in .NET 3.5, how they work and what can be done with them. After the break I'll then show how the new XML classes can be used in LINQ (Language INtegrated Query) in order to get data out in the way that you want.</p>
