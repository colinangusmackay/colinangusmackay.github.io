		<p>There is a meme going around at the moment and I thought I'd join in even although I've not been specifically tagged by it, it looks good fun. I spotted it on <a href="http://haacked.com/" target="_blank">Phil Haak's blog</a> <a href="http://haacked.com/archive/2008/07/25/how-i-got-started-in-software-development.aspx" target="_blank">with his response</a>.</p>  <h1>How old were you when you started programming?</h1>  <p>I was 8 years old.</p>  <h1>How did you get started in programming?</h1>  <p>When my dad bought a ZX Spectrum in 1983 (It was a Mark II, 48K RAM). I started by typing in programs from the manuals, then by creating my own programs. One of the first I remember creating was to stop my sister using the computer. She was younger than me and the program was something like this:</p>  <blockquote>   <p><font face="con" size="2">10 PRINT "How old are you?"       <br />20 INPUT a        <br />30 IF a &lt; 8 THEN PRINT "You are too young to use this computer."; GO TO 10</font></p> </blockquote>  <h1>What was your first language?</h1>  <p>ZX Spectrum Basic</p>  <h1>What was the first real program that you wrote?</h1>  <p>The first real program that I wrote as part of a job was a tool to summarise and format certain data in a database. What today would be handled by a few drag &amp; drop operations and some mouse clicks in SQL Server Reporting Services took me about a week or so back then. It was written in a language called Magik (yes, with a K)</p>  <h1>What languages have you used since you started programming?</h1>  <p>Well various flavours of BASIC (ZX Spectrum, BBC, Visual Basic, VBA, etc.), COMAL (used by my high school), PASCAL, C/C++, COBOL, Magik, javascript, C#. There are probably a whole slew of other languages that I've touched over the years but not spent any significant time with that I've missed out here.</p>  <h1>If you knew then what you know now, would you have started programming?</h1>  <p>Yes, I would still have started programming. I probably would have done it a lot better though. There are a lot of things I've learned along the way that I wish I knew earlier. But, then again, if I never made those mistakes what lessons would I be learning? I guess I would be answering this questions pretty much the same way, but thinking of a different set of mistakes. Or would I? Maybe, since I didn't make those mistakes in the first place I would end up being an incredibly arrogant insufferable arsehole.</p>  <h1>If there is one thing you learned along the way that you would tell new developers, what would it be?</h1>  <p>Last year, I interviewed for 3 months to hire a developer. From that, the one major thing I think people need to understand is that in software development you must continue to learn constantly. I was interviewing candidates with 10+ years experience that had pretty much never learned anything since leaving university. Sure, they were using new languages since leaving, but they never learned about how to really use this fancy new object oriented language, or how to defend against SQL Injection Attacks. Most of them couldn't even write a <a href="http://www.codinghorror.com/blog/archives/000781.html" target="_blank">fizz-buzz program</a> <a href="http://www.hanselman.com/blog/YouCantTeachHeightMeasuringProgrammerCompetenceViaFizzBuzz.aspx" target="_blank">for goodness sakes</a>.</p>  <p>So, my answer would be <strong><em>life long learning</em></strong>. If you don't want to do it then do something else.</p>  <h1></h1>  <h1>Who do I tag?</h1>  <p>It is an interesting set of questions, and I'd like to know the answer from the following people:</p>  <ul>   <li><a href="http://www.craigmurphy.com/blog/" target="_blank">Craig Murphy</a></li>    <li><a href="http://garyshortblog.wordpress.com/" target="_blank">Gary Short</a></li>    <li><a href="http://weblogs.asp.net/plip/" target="_blank">Phil Winstanley</a></li>    <li><a href="http://www.sturmnet.org/blog/" target="_blank">Oliver Sturm</a></li>    <li><a href="http://idunno.org/" target="_blank">Barry Dorrans</a></li> </ul>  <div class="wlWriterSmartContent" id="scid:0767317B-992E-4b12-91E0-4F059A8CECA8:d3b0982d-a718-481f-aa89-b85505d2213d" style="display:inline;margin:0;padding:0;">Technorati Tags: <a href="http://technorati.com/tags/meme" rel="tag">meme</a>,<a href="http://technorati.com/tags/software%20development" rel="tag">software development</a>,<a href="http://technorati.com/tags/programming" rel="tag">programming</a></div>
