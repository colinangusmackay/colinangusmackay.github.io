		<p>I've just had the email through to let me know that my session has been selected for <a href="http://www.sqlbits.com/" target="_blank">SQL Bits III</a> on the 13th of September. I'll be talking on the subject of <a href="http://www.colinmackay.net/Articles/AnIntroductiontoSpatialQueriesinSQLServer/tabid/164/Default.aspx" target="_blank">Spatial Queries in SQL Server 2008</a>, an evolving talk I've done a couple of times before. It will be updated once again for SQL Bits III.</p>  <p>Here's the abstract: It is reckoned that 80-90% of data has a spatial component to it. But what do we do with it now? At best, we constrain it to postcodes. Well, that would be great if we were delivering letters, but the majority of us aren’t. In this session we look at Spatial Queries in SQL Server to see how it works and what can be done with it.</p>  <div class="wlWriterSmartContent" id="scid:0767317B-992E-4b12-91E0-4F059A8CECA8:5e3da37f-2370-4942-895a-7ca7babfeee0" style="display:inline;margin:0;padding:0;">Technorati Tags: <a href="http://technorati.com/tags/SQL%20server" rel="tag">SQL server</a>,<a href="http://technorati.com/tags/SQLBits" rel="tag">SQLBits</a>,<a href="http://technorati.com/tags/SQLBits%20III" rel="tag">SQLBits III</a>,<a href="http://technorati.com/tags/Spatial%20Queries" rel="tag">Spatial Queries</a></div>
