		<p>It occured to me today as I was driving up the road from the <a href="http://www.blackmarble.co.uk/">Black Marble</a> event on Software Architecture that the number of posts on my blog has gone down recently. I was thinking about what happened. When I looked over the recent posts I discovered that I'm putting fewer community posts on my blog as I'm putting them up on the <a href="http://scottishdevelopers.com/">Scottish Developers</a> site instead.</p>
<p>So, if you are looking for all the community stuff I used to post then please visit the <a href="http://scottishdevelopers.com/">Scottish Developers</a> website as I'm posting it there instead. However, if it isn't relevant to Scotland I'll probably still post it here instead.</p>
<p>The <a href="http://scottishdevelopers.com/">Scottish Developers</a> website also contains details of any <a href="http://scottishdevelopers.com/events/">developer events in Scotland</a> that I'm told about.</p>
