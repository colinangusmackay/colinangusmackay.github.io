<p>Because the TFS Server where I work is not on the domain, it will prompt you for credentials each time you log in (unless you’ve previously used the web access and checked the “Remember Me” option). If you don’t want to use the web access portal, you can still get TFS to remember your credentials and not ask you each time you log in.<u></u><u></u></p>  <p><u></u><u></u></p>  <p>Go in to the control panel and select “User Accounts”<u></u><u></u></p>  <p><u></u><u><img style="float:none;margin-left:auto;display:block;margin-right:auto;" src="http://static.colinmackay.co.uk/images/tfs/2013-07-27-1-open-user-accounts.png" /></u></p>  <p><u></u><u></u></p>  <p>In the next screen click “Manage Windows Credentials”<u></u><u></u></p>  <p><u></u><u></u></p>  <p><u></u><u><img style="float:none;margin-left:auto;display:block;margin-right:auto;" src="http://static.colinmackay.co.uk/images/tfs/2013-07-27-2-manage-windows-credentials.png" /></u></p>  <p><u></u><u></u></p>  <p>In the next screen click “Add Windows Credential”<u></u><u></u></p>  <p><u></u><u></u></p>  <p><u></u><u><img style="float:none;margin-left:auto;display:block;margin-right:auto;" src="http://static.colinmackay.co.uk/images/tfs/2013-07-27-3-add-a-windows-credential.png" /></u></p>  <p><u></u><u></u></p>  <p>Then type your details into the form, and press “OK”<u></u><u></u></p>  <p><u></u><u></u></p>  <p><u></u><u><img style="float:none;margin-left:auto;display:block;margin-right:auto;" src="http://static.colinmackay.co.uk/images/tfs/2013-07-27-4-enter-credentials.png" width="600" height="335" /></u></p>  <p><u></u><u></u></p>  <p>You’ll see your new set of credentials appear in the Credential Manager page:<u></u><u></u></p>  <p><u></u><u></u></p>  <p><u></u><u><img style="float:none;margin-left:auto;display:block;margin-right:auto;" src="http://static.colinmackay.co.uk/images/tfs/2013-07-27-5-completed.png" width="600" height="457" /></u></p>  <p><u></u><u></u></p>  <p>Now when you open up Visual Studio it won’t prompt you for your credentials all the time.</p>
